## 👋 About Me

I'm **Trung Chien**, an Information Technology student at **PTIT** (Posts and Telecommunications Institute of Technology) in Hanoi, Vietnam. I enjoy turning technical ideas into working software and understanding how large systems run behind the scenes.

- 💻 **Backend:** building RESTful APIs with **Java** and **Spring Boot**, with authentication and authorization via Spring Security
- 🧩 **Architecture:** studying **microservices** and **distributed systems** (Spring Cloud, Kafka, Redis)
- 🐳 **DevOps basics:** containerizing apps with **Docker** and deploying them to real servers
- 🤖 **AI integration:** exploring how to add LLM features (Spring AI, RAG) to backend applications
- 🎯 **Goal:** design secure, stable, high-load backend systems
- 📫 **Status:** open to **Internship / Fresher Backend Java** opportunities
